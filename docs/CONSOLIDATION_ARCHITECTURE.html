The Consolidation Layer

Cheap authorship behind a real gate — the missing quadrant between pre-LLM systems (gates + expensive humans) and post-LLM systems (cheap authorship + no gate).

Consolidation priority S(c,t) w₁·log(density) + w₂·Σᵢ(t−tᵢ)−d + w₃·spread + w₄·max-sim(c, goals ∪ profile)

The historical pattern

Pre-LLM systems (Wikipedia, Zettelkasten, org-mode) had good gates powered by expensive humans. Post-LLM systems (MemGPT, GraphRAG, RAPTOR, Mem0) have cheap authorship and no gate at all. MIKAI's Consolidation Layer is the missing quadrant: cheap LLM authorship behind a deterministic, human-tunable gate. GraphRAG is the nearest neighbor; the delta is incremental maintenance, human-legible pages, and a personal (not corpus-statistical) salience function.

Reframe worth internalizing

"Worthy" is not a property of the concept. It's a property of (concept × current goals × time). Salience is non-stationary — "Graphiti patching" was page-worthy in May and is ambient now. The system needs demotion as a first-class, cheap operation. Once demotion is cheap, promotion errors are cheap, and full automation stops being risky. This is the real unlock — more than better LLM judgment.

The consistency wobble

A frontier model on good evidence makes reasonable one-shot promotion calls. What it cannot do is hold a stable threshold across thousands of independent calls over months. Uncalibrated per-item judgment drifts. Fix: make S deterministic; let the LLM only do what needs language understanding (boundary drawing, merge adjudication, page authoring). "LLM decides" means "LLM operates inside a scoring-and-policy harness" — never freelances the whole decision.

Path 2 wins the bootstrap

Brian seeds ~10 exemplars ("these deserve pages, roughly this order, one-line reasons") + 5 explicit negatives. System fits S's weights to reproduce the ranking, then proposes the next 20 candidates as a ranked batch with evidence cards. Verdicts become text in a promotion-policy doc that conditions every future LLM judge call — constitutional, like DECISIONS.md. After ~20 verdicts, per-item review ends; drop to 1-in-10 sampled audits + unconditional demotion. Path 1 (approval queue) already empirically failed — 24 proposals rotting in the inbox is the evidence.

Naming — Wikipedia's hard-won lesson

Concepts don't self-canonicalize. "Agent Memory" / "Memory Consolidation" / "Dual-memory problem" are the same topic; an LLM asked in three sessions mints all three unless resolution comes before mint. Pipeline: normalized alias-table exact match → embedding kNN over existing names+aliases → LLM merge adjudication only when candidates exist → mint new name only if all resolve empty. Aliases append-only; merges/renames logged and reversible. Without this apparatus, concept promotion is worse than no promotion — duplicated near-synonym pages fragment retrieval mass.
