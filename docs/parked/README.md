# Parked research

Tangents that surfaced in an execution session and were set down here instead of
being lost or derailing the build. Created by the `park-research` skill.

- Each `*.md` is a self-contained note routed to a target branch / doc.
- `INDEX.md` is the recurrence tally — a topic parked 3+ times is a candidate
  for crystallization into its own skill (`/oh-my-claudecode:learner`) or its
  own branch + charter.
- The authoritative home for a parked idea is the doc it was routed into
  (`docs/OPEN.md` O-### entries, `docs/FOUNDATIONS.md`, etc.). The stub here is
  the cross-branch breadcrumb, not the system of record.

See `.claude/charter.md` for the out-of-scope → destination routing map and
`.claude/skills/park-research/SKILL.md` for the procedure.
