Two halves of one Karpathy design

The write side is dumb. Every source funnels into the same port method, L3Backend.ingest_episode(). The active WikiAdapter appends the content verbatim, tagged with a date header and a source token, and writes one audit line to wiki-episodes.log. No extraction, no summarisation, no dedup, no re-encoding. The substrate accumulates raw material at ingest cost and nothing else. That intentional dumbness is why the corpus can grow to 27MB across eight sources without a coordination story: the union of writers cannot break each other because none of them share state beyond byte offsets.

The read side is compressed. Dream passes are the projection lens. narrative, ontology, and user-model each read the raw corpus, spend one LLM call, and emit a small file downstream consumers can afford to hold in a prompt. compact is the deterministic garbage-collector: it rewrites wiki.md deduped, no model in the loop. Together they turn an ever-growing log into a handful of always-fresh, prompt-shaped views — Karpathy's read/write asymmetry realised as file operations rather than embeddings.

The one broken arrow to flag. The Attention Engine still reads live threads, not the derived files. That is the "stale-substrate drift" the parallel ARCHITECTURE_FLOW.html audit called out in its top-three simplifications: two attention paths, one grounded in raw threads and one in dream outputs, will keep disagreeing until they collapse onto the same substrate.

Roadmap · not shown yet

What the diagram doesn't have — yet

A tensions dream pass. There are already 26 tensions living inside wiki.md, written by hand or by earlier extraction. No current pass regenerates them from the corpus; the Inspector reads them straight from the raw file. A fifth dream pass with the same shape as narrative would close that loop.

Vector embeddings. Not required today. The FTS index handles retrieval well enough at 27MB. The plan is to add an embedding pass only if trigger conditions fire — corpus growth, recall degradation, or a consumer that specifically needs semantic search over the raw substrate.

Historical backfill was a one-shot. The Neo4j → wiki migration on 2026-08-06 (8,048 episodes) is drawn dashed because it will never run again. Steady-state ingestion is only the six live sources above it.
