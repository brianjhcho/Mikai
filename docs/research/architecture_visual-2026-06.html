Architecture A

Anthropic Dreaming

Launched 2026-05-06 as a research preview. Asynchronous job that reviews up to 100 past agent session transcripts plus an existing memory store, and produces a curated new memory store consisting of plain-text notes and structured playbooks. Target: agent self-improvement inside Anthropic's runtime. Models: claude-opus-4-7, claude-sonnet-4-6.

Key properties

  • Input scope: Anthropic-runtime sessions only — no cross-source ingestion
  • Output ownership: opaque memory store inside Anthropic's runtime
  • Consumer: Future agent sessions of the same agent class
  • Access: research preview, API-only, requires form request
  • Optimization target: agent task performance over time
Architecture B

MIKAI — Personal Context Engine

Cross-source ingestion into a Graphiti L3 substrate (12,849 entities, 18,510 edges, 3,455 episodes as of 2026-06-15). Three scheduled Claude Code skills consolidate evidence into user-owned markdown identity files. Downstream projects (Village mentor, weekend planner, taste-furniture, etc.) compose identity files with per-use-case retrieval recipes for any LLM or agent the user points at them.

  • Output ownership: user-owned markdown files on user's filesystem

  • Access: open — runs on Max plan + Claude Code, no special access
  • Optimization target: user reasoning continuity across surfaces
  • Wedge: cross-source + file-based + recipe library + mentor authoring

What this means strategically

  • Mechanism convergence is correct. Both systems converge on scheduled async LLM-as-curator because that's the right pattern for the problem class. MIKAI's MEMORY_ARCHITECTURE_THESIS.md (March 2026) specced this 11 weeks before Dreaming's research-preview launch.
  • Scope divergence is permanent. Cross-source ingestion, user-owned files, and platform-agnostic consumers are MIKAI's structural commitments — not feature gaps Anthropic will close because Anthropic's business model doesn't pull it there.
  • Dreaming generalizing to Projects is the risk to watch. If Anthropic extends Dreaming to ingest a Project's conversation history and curate Project memory, the within-Claude slice of MIKAI's wedge gets absorbed. Monitor for: Apple Notes Connector gaining scheduled ingestion, Claude Projects gaining auto-edit of project files.
  • The hedge is to ship α v1 by Q3 2026. Cross-source + file-based + recipe library + mentor authoring as the 4-property wedge, established before Anthropic generalizes.
